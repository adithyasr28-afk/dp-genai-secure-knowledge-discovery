# Screenshot index

Every image here is a genuine capture of the running dashboard (`app.py`, Streamlit 1.64.0) at `http://localhost:8517`, on Windows 11.

- **No image was edited**, apart from cropping where stated.
- **No result or API response was mocked.**
- No API key, `.env` content or personal data is visible: the key is never rendered by the app, and the only local file path shown, the audit-record line, was cropped off.

## 2026-10-12: full feature set (`2026-10-12/`)

**How they were captured:**
- by `capture_screenshots.py`, which drives headless Chrome through the DevTools protocol and clicks only the dashboard's own controls;
- 1600 CSS px wide at device scale 1.25, giving PNG files 2,000 px wide;
- light theme;
- full page height, capped at 6,000 CSS px (7,500 px).

**UI demonstration run:** screenshots 03–08 come from a run started in the UI, **PrivBayes, ε = 3, seed 7**. This run is **not** one of the 41 reported runs. It appended a log record and wrote a CSV. Both were removed afterwards (`git checkout -- results/`), and the log is back to 43 records.
